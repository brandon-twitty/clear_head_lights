# Kelley's Clear Headlights Portal 🚗✨

Welcome to the internal source code for **Kelley's Clear Headlights**. This platform is a custom-built B2B CRM, Dealership Portal, and Lead Intake System designed to streamline partnerships, manage dealerships, and schedule headlight restorations.

## 🏗️ Architecture & Tech Stack

This project is built using modern web technologies to ensure a fast, secure, and responsive user experience:
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Database:** Firebase Firestore
- **Authentication:** Firebase Auth
- **Emails:** Resend API
- **Hosting:** Firebase App Hosting (CI/CD via GitHub)

---

## 🗺️ Project Structure & Navigation

The application is split into several key areas depending on the user's role and purpose:

### Public Pages
- **`/` (Home):** The main landing page showcasing the brand and services.
- **`/partnership`:** A lead-intake application form where new businesses can apply to become partnered dealerships.
- **`/login`:** The universal authentication page for both Admins and Dealers.

### Secure Portals
- **`/register`:** An invite-only registration page. Dealerships must have a secure invite token generated by an admin to create an account here.
- **`/admin`:** The locked-down CRM dashboard. Only accessible to users with the `admin` role. Used for managing users, viewing leads, and generating invite links.
- **`/dealer`:** The dedicated B2B portal. Only accessible to users with the `dealer` role. Used by partners to manage their account and schedule services.

---

## 🔒 Security Rules & Database

We rely on Firebase Firestore for our backend database. The core collections include:
- `users`: Stores account information and custom roles (`role: 'admin' | 'dealer'`).
- `leads`: Stores submissions from the `/partnership` form.
- `invites`: Stores secure, single-use tokens generated by Admins for new dealers.
- `appointments`: Stores scheduled service requests.

*Note: All database reads/writes are strictly protected by `firestore.rules` to ensure dealers can only see their own data, and only admins can access global collections.*

---

## 🚀 Deployment & App Hosting

This project is automatically deployed to **Firebase App Hosting**. 

Every time code is pushed to the `main` branch on GitHub, Firebase automatically kicks off a new rollout. 
- **Public Environment Variables:** Managed via the `.env` file checked into source control.
- **Secrets (like Resend API Keys):** Managed securely via Google Cloud Secret Manager and linked to the build via `apphosting.yaml`.

## 💻 Local Development

To run the project locally on your machine:

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start the Development Server:**
   ```bash
   npm run dev
   ```

3. **Open the App:**
   Navigate to [http://localhost:3000](http://localhost:3000) in your browser.
